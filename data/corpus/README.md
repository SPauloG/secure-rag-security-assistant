# Corpus

The documents are kept out of git (see `.gitignore`); only this README and
`.gitkeep` are versioned. To reproduce the corpus, download the files below
using these names.

| File | Source | Format |
|---|---|---|
| `owasp-top10-llm-2025.pdf` | OWASP Top 10 for LLM Applications 2025 — https://genai.owasp.org/resource/owasp-top-10-for-llm-applications-2025/ | PDF, 45 pages |
| `owasp-top10-2021-a01.html` … `a10.html` | OWASP Top 10:2021 — `https://owasp.org/Top10/2021/<A0X_2021-Name>/index.html` (one page per category) | HTML |
| `nist-csf-2.0.pdf` | NIST Cybersecurity Framework 2.0 (CSWP 29) — https://nvlpubs.nist.gov/nistpubs/CSWP/NIST.CSWP.29.pdf | PDF, 32 pages |

Why these documents: see the "Corpus" section of the main README.
